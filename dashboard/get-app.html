Get the FixPilot app for Windows

The support desk runs in the cloud. The FixPilot app runs on the customer's PC, because it is the part that sees the screen and uses the mouse and keyboard. It only starts after the customer enters a support code and presses Accept.

Download FixPilot (ZIP) View the code on GitHub
Needs Windows 10 or 11, Python 3.11 or newer, a Gemini API key, and the FixPilot access token from the team.

Set up and use it

  1. Install Python

    From python.org. In the installer, tick Add python.exe to PATH.

  2. Unzip FixPilot and run INSTALL_FIXPILOT.bat

    Once per PC. It installs everything and asks for your Gemini API key (free from Google AI Studio) and the FixPilot access token. It then checks the connection to the support desk.

  3. Start it with START_FIXPILOT.bat

    The FixPilot panel opens docked on the right edge of the screen. Open the software you need help with on the left.

  4. Enter the support code

    Support creates a 6-digit code on the support desk. In the panel, open Support code, type it, read the request and choose Just fix it, Ask first or Guide me.

  5. Press Accept and watch it work

    Each step shows in the panel and on the support desk at the same time. Press STOP or Ctrl+Shift+X at any moment.

Why an app and not a web page?

It acts on your PC

A website is not allowed to move your mouse or read your screen. That is why AnyDesk and TeamViewer are apps too.

Nothing happens without you

A support code plus your Accept starts a session. Choose Ask first to approve every click.

Your passwords stay yours

At a password box FixPilot pauses and you type it. It never reads or stores it.

Judging FixPilot? The quickest way to see it work is the live demo on our laptops or the demo video. To run it yourself, follow the steps above and ask the team for the access token.
